# 🍽️ Pett Pooja – AI Recipe Generator

Pett Pooja is an AI-powered recipe generator that helps users create recipes using the ingredients they already have at home.

## ✨ Features

- Generate recipes using Google Gemini AI.
- Enter available ingredients.
- Choose dietary preferences.
- Select your preferred cooking time.
- Save and view recipe history.
- Copy generated recipes.
- Download recipes as text files.
- Dark mode and light mode.
- Loading indicator while generating recipes.
- Error handling for missing API keys and invalid inputs.
- Responsive design for desktop and mobile devices.

## 🛠️ Technologies Used

- HTML
- CSS
- JavaScript
- Google Gemini API
- Local Storage

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Open `index.html` using the Live Server extension.
4. Open the API Settings section.
5. Get a Gemini API key from [Google AI Studio](https://aistudio.google.com/app/apikey).
6. Paste your API key and click **Save API Key**.
7. Enter the ingredients you have.
8. Select your dietary preference and cooking time.
9. Click **Generate Recipe**.

## 🔑 API Key Information

This project uses the Google Gemini API to generate recipes.

Users must provide their own API key through the API Settings section. The key is stored in browser Local Storage and is not included in the GitHub repository.

**Note:** This browser-based API key storage is suitable for a learning project, but it is not secure for a public production application.
